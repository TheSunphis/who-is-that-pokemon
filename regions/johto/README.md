# Johto Pokémon quiz images

Source Pokédexes: [`updated-johto`](https://pokeapi.co/api/v2/pokedex/updated-johto/) (256 entries). There are 256 unique species across 256 regional entries.

The generator expands every listed species to all PokeAPI varieties. It rendered 358 forms as paired images in `silhouettes/` and `revealed/`. Each revealed image replaces the question mark with the Pokémon/form name. This includes regional forms and battle forms such as Ultra Necrozma when PokeAPI provides official artwork. See `manifest.json` for each file and source URL.

Pokémon names and artwork are the property of their respective rights holders; artwork is fetched from PokeAPI's sprite data.
