# Galar Pokémon quiz images

Source Pokédexes: [`galar`](https://pokeapi.co/api/v2/pokedex/galar/) (400 entries), [`isle-of-armor`](https://pokeapi.co/api/v2/pokedex/isle-of-armor/) (211 entries), [`crown-tundra`](https://pokeapi.co/api/v2/pokedex/crown-tundra/) (210 entries). There are 584 unique species across 821 regional entries.

The generator expands every listed species to all PokeAPI varieties. It rendered 779 forms as paired images in `silhouettes/` and `revealed/`. Each revealed image replaces the question mark with the Pokémon/form name. This includes regional forms and battle forms such as Ultra Necrozma when PokeAPI provides official artwork. See `manifest.json` for each file and source URL.

Pokémon names and artwork are the property of their respective rights holders; artwork is fetched from PokeAPI's sprite data.
