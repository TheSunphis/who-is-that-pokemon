# Kalos Pokémon quiz images

Source Pokédexes: [`kalos-central`](https://pokeapi.co/api/v2/pokedex/kalos-central/) (153 entries), [`kalos-coastal`](https://pokeapi.co/api/v2/pokedex/kalos-coastal/) (153 entries), [`kalos-mountain`](https://pokeapi.co/api/v2/pokedex/kalos-mountain/) (151 entries), [`lumiose-city`](https://pokeapi.co/api/v2/pokedex/lumiose-city/) (232 entries), [`hyperspace`](https://pokeapi.co/api/v2/pokedex/hyperspace/) (132 entries). There are 582 unique species across 821 regional entries.

The generator expands every listed species to all PokeAPI varieties. It rendered 793 forms as paired images in `silhouettes/` and `revealed/`. Each revealed image replaces the question mark with the Pokémon/form name. This includes regional forms and battle forms such as Ultra Necrozma when PokeAPI provides official artwork. See `manifest.json` for each file and source URL.

Pokémon names and artwork are the property of their respective rights holders; artwork is fetched from PokeAPI's sprite data.
